TTS 服务

支持 OpenAI 兼容接口和 MiniMax
本地 Kokoro：provider=openai，base_url=http://127.0.0.1:8399，model 留空。

公网示例

OpenAI：provider=openai，base_url=https://api.openai.com/v1，model=tts-1，填 API Key。
千问 DashScope：provider=openai，base_url=https://dashscope.aliyuncs.com/compatible-mode/v1，model=qwen-tts，音色如 Cherry。
MiniMax：provider=minimax，base_url=https://api.minimax.chat/v1/t2a_v2?GroupId=你的GroupId，model=speech-01-turbo，音色用 MiniMax voice_id。
